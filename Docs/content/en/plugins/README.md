# Plugins

Extend AuthKit without forking it. Pick plugin to learn what it does, or write your own behind the stable contract.

- [DevTokens](/plugins/devtokens/) issues and validates developer tokens for SDK access.
- [DevTools](/plugins/devtools/) Swagger, gRPC exploration, and an embedded UI inside the running server.
- [Custom plugins](/plugins/custom/) ship your own behavior behind `IAuthKitPlugin`.

New to AuthKit? Start with [Introduction](/guide/introduction/).
