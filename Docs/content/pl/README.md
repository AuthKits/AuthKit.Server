# Dokumentacja AuthKit

Witaj w AuthKit — usłudze uwierzytelniania deweloperów i dostępu do SDK.

## Przegląd

AuthKit to **usługa oparta na wtyczkach** do **uwierzytelniania deweloperów, wydawania tokenów SDK i weryfikacji dostępu**. Gwarantuje, że tylko autoryzowani deweloperzy mają dostęp do metod SDK, zapewniając bezpieczny i audytowalny mechanizm uwierzytelniania oparty na tokenach.
