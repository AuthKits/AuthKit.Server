# Wtyczki

Rozszerzaj AuthKit bez forkowania. Wybierz wtyczkę, żeby poznać co robi, albo napisz własną za stabilnym kontraktem.

- [DevTokens](/pl/plugins/devtokens/) wydaje i weryfikuje tokeny deweloperskie do dostępu SDK.
- [DevTools](/pl/plugins/devtools/) Swagger, eksploracja gRPC i osadzony UI w działającym serwerze.
- [Własne wtyczki](/pl/plugins/custom/) dostarczaj własne zachowanie za `IAuthKitPlugin`.

Nowy w AuthKit? Zacznij od [Wprowadzenia](/pl/guide/introduction/).
